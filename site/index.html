THE TOOLKIT

Everything around the model

Small, composable commands take you from dataset files to readable evaluation outputs.

01 / DATA

Prepare clean splits

Convert annotations to a normalized format and keep screenshots separated across data splits.

vpopsd.prepare
02 / TRAIN

Run a training job

Configure a single-device run with LoRA or full-model updates using a YAML file.

03 / EVALUATE

Inspect model outputs

vpopsd.evaluate

QUICK START

Up and running in minutes

Use Python 3.12 and a CUDA-compatible PyTorch installation for training.

01

Install

git clone https://github.com/tjucrush/visual-privileged-opsd-main.git
cd visual-privileged-opsd-main
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev,data]'

Install a matching PyTorch and torchvision build for your CUDA version first.

02

Try an example

python -m vpopsd.demo
python -m vpopsd.evaluate \
  --data outputs/demo/examples.jsonl \
  --predictions outputs/demo/predictions.jsonl \
  --output-dir outputs/demo/eval

On Windows, activate the environment with .venv\Scripts\Activate.ps1.

WORKFLOW

From records to results

01

Data preparation

Each JSONL entry contains an instruction, a screenshot, and an xyxy bounding box normalized to [0,1]. The converter accepts custom field names and pixel or normalized units; the splitter groups identical screenshots to avoid leakage between train and validation sets.

02

Training

Start from the supplied YAML configuration, choose LoRA or full fine-tuning, and direct each run to its own output folder. Saved outputs include configuration, dataset metadata, training metrics, and model weights.

python -m vpopsd.train --config configs/qwen3_vl_8b.yaml
03

Evaluation

Run a single dataset or use the benchmark suite. Results include per-dataset accuracy, macro and micro aggregates, predictions, and detailed records.

python -m vpopsd.evaluate --data data/benchmarks/screenspot/test.jsonl --config configs/eval_base.yaml --output-dir outputs/eval-base

工作流程

从数据记录到评估结果

01

数据准备

每条 JSONL 记录包含指令、截图和归一化到 [0,1] 的 xyxy 边界框。转换工具支持自定义字段名及像素或归一化坐标单位；划分时会按截图内容分组，避免训练集和验证集发生图片泄漏。

02

模型训练

从提供的 YAML 配置启动训练，选择 LoRA 或全量微调，并为每次运行指定独立输出目录。保存内容包括配置、数据集元信息、训练指标和模型权重。

python -m vpopsd.train --config configs/qwen3_vl_8b.yaml
03

效果评估

可运行单数据集评估或完整基准测试套件。结果包含各数据集准确率、宏微平均指标、预测结果和详细记录。

python -m vpopsd.evaluate --data data/benchmarks/screenspot/test.jsonl --config configs/eval_base.yaml --output-dir outputs/eval-base
